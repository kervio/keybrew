# Changelog

All notable changes to Keybrew will be documented here. This project follows Semantic Versioning.

## Unreleased

### Added

- Dependency-free Hebrew virtual keyboard with caret-aware editing.
- Floating and inline placement with automatic viewport handling.
- Mobile, desktop, and combined device targeting.
- Optional niqqud, number, and symbol panels.
- Manual icon-trigger activation and while-open native-keyboard suppression.
- Accessible controls, lifecycle callbacks, and bubbling custom events.
- CommonJS, ES module, browser-global, CSS, and TypeScript entry points.
